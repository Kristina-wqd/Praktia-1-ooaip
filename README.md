## ПР2 (Часть 2). Реализация интерфейсов

Все файлы находятся в `src/praktika2/part2/`.

* **Movable / MovablePoint / MovableRectangle:** движение точки и прямоугольника, проверка скорости через `SpeedTest()`
* **MathCalculable / MathFunc:** возведение в степень, модуль комплексного числа, число PI
* **StringProcessing / ProcessStrings:** подсчёт символов, символы на нечётных позициях, инверсия строки
* **Printable / Book / Magazine:** вывод книг и журналов через `instanceof`
* **UML-диаграмма:** файл `uml_movable.png`

## ПР2 (Часть 3). Работа с датой и временем

Все файлы находятся в `src/praktika2/part3/`.

* **Task1:** вывод фамилии, даты получения и сдачи задания через класс `Date`
* **Task2:** сравнение текущей даты с датой, введённой пользователем
* **Student / Task3:** класс `Student` с датой рождения и форматированием через `SimpleDateFormat`
* **Task4:** создание объектов `Date` и `Calendar` по данным, введённым пользователем
* **Task5:** сравнение производительности `ArrayList` и `LinkedList` (add, get, remove)
